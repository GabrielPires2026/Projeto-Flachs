# Projeto-Flachs

# O que é o Projeto Flachs:
É uma plataforma de marketplace dedicada a resolver a esclusão logistica das periferias de modo a intermediar o acesso a produtos e serviços em uma interface intuitiva, que abrange 
diferentes públicos desde os vendedores, empresários e entregadores até os usuários e clientes, permitindo o livre acesso aos serviços de modo que os entregadores consigam acessar e
participar do processo de entregas e possibilitando aos clientes acessarem os produtos disponiveis. 


# Quais caminhos serão seguidos

De início, o escopo do projeto é o desenvolvimento de uma aplicação web MVP que funciona como uma ponte entre consumidores, entregadores e vendedores/empresas, com interfaces diferentes para cada tipo de usuário.

O sistema permitirá administração, divulgação e venda de produtos e serviços, além de um módulo para aceitar ou recusar entregas.

Como diferencial de modelo de negócio, o sistema foi desenhado considerando a hipótese de priorização de entregadores que residam nas periferias atendidas, partindo do pressuposto de que o conhecimento local pode tornar a entrega mais eficiente. Essa lógica é tratada como uma regra de priorização no algoritmo, e não como uma operação logística já em execução.
